# Toutiao Publisher v2.0.0

头条内容发布全流程自动化Skill - 配图生成、排版优化、一键发布。

## 功能特性

- 🎨 **智能配图**：整合最新版通用配图生成大师Skill v2.4.1，根据文章主题自动生成统一风格配图
- 📝 **专业排版**：头条号专属排版规范，提升可读性和完读率
- 🚀 **一键发布**：自动化发布流程，从内容到上线无缝衔接
- ✅ **质量检查**：发布前合规检查，避免违规和审核失败
- 🖼️ **配图方法论**：包含完整的ILLUSTRATION_SKILL.md（v2.4.1），8步SOP+质量评估+内容类型适配+行业垂直适配+品牌VI+心理学+快速模板库+工作流自动化+法律风险指南

## 适用场景

- 头条号（今日头条）文章发布
- AI+时政、AI+汽车、AI+科技领域深度长文
- 批量内容生产和发布

## 快速开始

1. 将本Skill目录复制到你的Skills目录
2. 在对话中引用本Skill
3. 按照SKILL.md中的流程执行
4. 配图生成参考ILLUSTRATION_SKILL.md

## 目录结构

```
toutiao-publisher/

└── README.md             # 项目说明
```
