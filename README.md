# Toutiao Publisher v3.0.0

头条内容发布全流程自动化Skill - 文章写好后的执行环节 = 配图生成 + 排版优化 + 一键发布。

## ⚠️ 第一原则

**文字和插画是核心内容（创造价值），排版只是辅助工具（降低阅读门槛）。**

- 配图生成：用做图skill v3.0.1给文章画插画和封面图
- 排版优化：用排版skill v2.0.0做好文章排版，降低阅读门槛
- 一键发布：成功发布到头条平台，确保排版和配图不丢失

## 定位

本Skill专注于**文章写好后的执行环节**，不包含内容创作和运营技巧：

- ✅ 配图生成：给文章画上插画和封面图（用做图skill v3.0.1）
- ✅ 排版优化：做好文章排版，提升可读性和完读率（用排版skill v2.0.0）
- ✅ 一键发布：成功发布到头条平台，确保排版和配图不丢失
- ❌ 内容创作（选题/标题/正文写作）- 待开发独立skill
- ❌ 运营技巧（推荐机制/流量获取/粉丝运营）- 待开发独立skill
- ❌ 数据复盘（核心指标/数据分析/优化方向）- 待开发独立skill

## v3.0.0核心升级

**吸取做图和排版skill经验，解决发布前检查不系统、配图排版经常丢失的问题**：

1. **第一原则**：明确发布助手的核心定位和目标
2. **10项必选发布元素**：标题、封面图、正文配图、小标题、正文段落、列表和引用、颜色系统、分类和标签、原创声明、手机端预览
3. **发布负面清单**：4大类绝对不要做的事情（配图问题、排版问题、发布操作问题、内容合规问题）
4. **发布前检查清单**：10项，发布前必须逐项确认
5. **发布后检查清单**：10项，发布后必须逐项检查，不合格返工
6. **版本引用更新**：配图skill v3.0.1，排版skill v2.0.0

## 功能特性

- 🎨 **智能配图**：整合最新版通用配图生成大师Skill v3.0.1，10项必选元素+结构化Prompt+强化负面提示词+检查流程
- 📝 **专业排版**：整合最新版通用排版大师Skill v2.0.0，第一原则+10项必选元素+简洁清爽原则+排版负面清单+检查流程
- 🚀 **一键发布**：自动化发布流程，从内容到上线无缝衔接
- ✅ **质量检查**：发布前/发布后完整检查清单（各10项），避免违规和审核失败

## 快速开始

1. 将本Skill目录复制到你的Skills目录
2. 在对话中引用本Skill
3. 文章写好后，按照SKILL.md中的流程执行：
   - 配图生成（参考ILLUSTRATION_SKILL.md v3.0.1）
   - 排版优化（参考TYPOGRAPHY_SKILL.md v2.0.0）
   - 一键发布（参考SKILL.md第三章）
   - 发布前检查（10项必选发布元素+发布前检查清单）
   - 发布后检查（发布后检查清单，不合格返工）

## v3.0.0 10项必选发布元素速查

| 序号 | 必选元素 | 检查标准 |
|------|---------|---------|
| 1 | 标题 | 20-30字，包含核心关键词，有悬念或冲突感 |
| 2 | 封面图 | 1张，1920x1080，风格统一，无元信息文字 |
| 3 | 正文配图 | 4-6张，位置在小标题上方，风格统一 |
| 4 | 小标题 | 统一编号（一、二、三），4-10字，前后空行 |
| 5 | 正文段落 | 每段不超过3行，段间空行，关键数据加粗 |
| 6 | 列表和引用 | 列表项不超过7个，金句用引用块 |
| 7 | 颜色系统 | 只使用红/橙/蓝+黑/白，颜色有语义 |
| 8 | 分类和标签 | 已选择正确分类，已添加3-5个相关标签 |
| 9 | 原创声明 | 已勾选（如适用） |
| 10 | 手机端预览 | 已手机端预览检查，排版和配图都正常 |
