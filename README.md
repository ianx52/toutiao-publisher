# Toutiao Publisher

头条内容发布全流程自动化Skill - 配图生成、排版优化、一键发布。

## 功能特性

- 🎨 **智能配图**：根据文章主题自动生成科技感插画风格配图
- 📝 **专业排版**：头条号专属排版规范，提升可读性和完读率
- 🚀 **一键发布**：自动化发布流程，从内容到上线无缝衔接
- ✅ **质量检查**：发布前合规检查，避免违规和审核失败

## 适用场景

- 头条号（今日头条）文章发布
- AI+时政、AI+汽车、AI+科技领域深度长文
- 批量内容生产和发布

## 快速开始

1. 将本Skill目录复制到你的Skills目录
2. 在对话中引用本Skill
3. 按照SKILL.md中的流程执行

## 目录结构

```
toutiao-publisher/
├── SKILL.md      # Skill主文件，包含完整流程
└── README.md     # 项目说明
```
