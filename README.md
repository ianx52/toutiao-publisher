# Toutiao Publisher v3.13.0

头条内容发布全流程自动化Skill - 文章写好后的执行环节 = 配图生成 + 排版优化 + 一键发布。

## ⚠️ 第一原则

**文字和插画是核心内容（创造价值），排版只是辅助工具（降低阅读门槛）。**

- 配图生成：用做图skill v3.1.0给文章画插画和封面图
- 排版优化：用排版skill v2.0.0做好文章排版，降低阅读门槛
- 一键发布：成功发布到头条平台，确保排版和配图不丢失

## 定位

本Skill专注于**文章写好后的执行环节**，不包含内容创作和运营技巧：

- ✅ 配图生成：给文章画上插画和封面图（用做图skill v3.1.0）
- ✅ 排版优化：做好文章排版，提升可读性和完读率（用排版skill v2.0.0）
- ✅ 一键发布：成功发布到头条平台，确保排版和配图不丢失
- ✅ 多平台支持：头条、公众号、小红书、微博（公众号详细，其他框架）
- ❌ 内容创作（选题/标题/正文写作）- 由写作skill负责（ian-content-writer v1.0.0）
- ❌ 运营技巧（推荐机制/流量获取/粉丝运营）- 待开发独立skill
- ❌ 数据复盘（核心指标/数据分析/优化方向）- 待开发独立skill

## 快速开始

1. 将本Skill目录复制到你的Skills目录
2. 在对话中引用本Skill
3. 文章写好后，按照SKILL.md中的流程执行：
   - 配图生成（参考ILLUSTRATION_SKILL.md v3.0.1）
   - 排版优化（参考TYPOGRAPHY_SKILL.md v2.0.0）
   - 一键发布（参考SKILL.md第五章）
   - 发布前检查（10项必选发布元素+发布前检查清单）
   - 发布后检查（发布后检查清单，不合格返工）

## v3.13.0 10项必选发布元素速查

| 序号 | 必选元素 | 检查标准 |
|------|---------|---------|
| 1 | 标题 | 20-30字，包含核心关键词，有悬念或冲突感 |
| 2 | 封面图 | 1张，1920x1080，风格统一，无元信息文字 |
| 3 | 正文配图 | 4-6张，位置在小标题上方，风格统一 |
| 4 | 小标题 | 统一编号（一、二、三），4-10字，前后空行 |
| 5 | 正文段落 | 每段不超过3行，段间空行，关键数据加粗 |
| 6 | 列表和引用 | 列表项不超过7个，金句用引用块 |
| 7 | 颜色系统 | 只使用红/橙/蓝+黑/白，颜色有语义 |
| 8 | 分类和标签 | 已选择正确分类，已添加3-5个相关标签 |
| 9 | 原创声明 | 已勾选（如适用） |
| 10 | 手机端预览 | 已手机端预览检查，排版和配图都正常 |
