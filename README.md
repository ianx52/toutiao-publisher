# Toutiao Publisher v2.1.0

头条内容发布全流程自动化Skill - 文章写好后的执行环节 = 配图生成 + 排版优化 + 一键发布。

## 定位

本Skill专注于**文章写好后的执行环节**，不包含内容创作和运营技巧：

- ✅ 配图生成：给文章画上插画和封面图
- ✅ 排版优化：做好文章排版，提升可读性和完读率
- ✅ 一键发布：成功发布到头条平台，确保排版和配图不丢失
- ❌ 内容创作（选题/标题/正文写作）- 待开发独立skill
- ❌ 运营技巧（推荐机制/流量获取/粉丝运营）- 待开发独立skill
- ❌ 数据复盘（核心指标/数据分析/优化方向）- 待开发独立skill

## 功能特性

- 🎨 **智能配图**：整合最新版通用配图生成大师Skill v2.4.1，根据文章主题自动生成统一风格配图
- 📝 **专业排版**：整合最新版通用排版大师Skill v1.0.0，与配图风格完全统一，提升可读性和完读率
- 🚀 **一键发布**：自动化发布流程，从内容到上线无缝衔接
- ✅ **质量检查**：发布前/发布后完整检查清单，避免违规和审核失败

## 适用场景

- 头条号（今日头条）文章发布
- AI+时政、AI+汽车、AI+科技领域深度长文
- 文章写好后的配图、排版、发布全流程

## 风格统一

配图和排版使用完全统一的风格系统：

| 颜色名称 | 色值 | 用途 |
|----------|------|------|
| 金句红 | #E53935 | 金句高亮、核心观点、引用左边框 |
| 数据橙 | #FB8C00 | 关键数据、事实数字、统计信息 |
| 判断蓝 | #1E88E5 | 小标题、分析判断、结论总结 |
| 线稿黑 | #212121 | 正文文字、标题文字、配图线稿 |
| 背景白 | #FFFFFF | 页面背景、引用块背景、配图背景 |

IP角色：「小黑」（黑色实心小圆点，白点眼，细腿，表情丰富）

## 快速开始

1. 将本Skill目录复制到你的Skills目录
2. 在对话中引用本Skill
3. 文章写好后，按照SKILL.md中的流程执行：
   - 配图生成（参考ILLUSTRATION_SKILL.md）
   - 排版优化（参考TYPOGRAPHY_SKILL.md）
   - 一键发布（参考SKILL.md第三章）
